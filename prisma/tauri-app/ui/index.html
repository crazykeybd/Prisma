框架说明

关键词驱动 + 数据驱动：测试剧本以 Excel 描述（sheet 名 testcase），框架自动完成运行目录创建、 输入卡与可执行程序拷贝、程序执行、结果提取与回填。支持生产者/消费者并行执行与模拟/真实两种运行模式。

新增关键词

自定义关键词用于适配其他被测软件：可以复用内置动作（只改字段标签与说明）， 也可以用命令行模板直接调用新软件。保存后立即出现在剧本编辑器的动作下拉里。

字段定义：列 0 固定为运行目录，列 2 固定为对象列，其余列按顺序作为参数 1~4。
列号 角色 标签 占位提示 必填

新建测试剧本

按模板批量生成用例：每个用例自动包含「准备运行目录 → 修改输入卡（可选）→ 运行被测软件 → 检查结果（可选）」， 一步到位，无需逐行手动填写。

参数矩阵（可选） 每行一个变量或检查项，各列对应一个用例；留空表示该用例不产生这一步。
